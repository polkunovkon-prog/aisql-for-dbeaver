# AI SQL for DBeaver

Плагин «ИИ-исполнитель SQL» для **DBeaver CE**: набор инструментов выполнения
SQL для встроенного ИИ-чата DBeaver + команды «выделил → спросил» + страница
настроек + журнал аудита — с корпоративным уровнем защиты данных
(политика администратора, маскирование + детекция ПДн, защита от
промпт-инъекций, аудит с экспортом в SIEM).

Плагин **не патчит файлы DBeaver** и не заменяет его функции — он регистрирует
собственные OSGi-бандлы и штатные расширения DBeaver:

- **Инструменты в ИИ-чате** — 14 функций тулбокса `db`: поиск объектов
  и образцы строк таблиц, выполнение read-only запросов, изменение данных
  и схемы, исследование объектов, макросы, структурная валидация SQL;
- **Команды «спроси ИИ»** — `Ctrl+Alt+A` (выделенный SQL в редакторе) и
  `Ctrl+Alt+I` (выделенные строки в таблице результатов): текст вставляется
  в поле ввода ИИ-чата без автоотправки;
- **Правка выделения ИИ** — `Ctrl+Alt+E` в SQL-редакторе: инструкция →
  точечные замены с подсветкой «было/стало» прямо в редакторе; список замен
  с галочками и переходом `Alt+↓`/`Alt+↑`, выборочное применение →
  «Применить» (один `Ctrl+Z` отменяет); запасной путь — «В чат»;
- **Страница настроек** — «Статус защиты», профили безопасности подключений,
  запрещённые конструкции, маскирование + детекция ПДн, режим защиты от
  промпт-инъекций, лимиты, журнал аудита и syslog, корпоративная политика;
- **Журнал аудита** — `ai-sql-audit.jsonl` с цепочкой SHA-256 (подделка
  содержимого обнаруживается проверкой) и экспортом событий в SIEM;
- **Корпоративная политика** — `ai-sql-enterprise.properties`: настройки,
  зафиксированные администратором, пользователь ослабить не может;
  инструменты можно отключать целиком (`tools.disabled`); fail-closed.

## Требования

- Linux + DBeaver CE **26.1.x–26.2.x** (сборка и тесты проверены на 26.1.5
  и 26.2.2);
- JDK 21+ (только для сборки);
- `xvfb` — для автоматической регистрации бандлов при установке
  (`sudo apt install xvfb`, если ещё не установлен).

## Быстрый старт

```bash
# 1. Сборка (javac против jar-ов установленного DBeaver, без Maven)
./releng/build.sh

# 2. Офлайн-тесты (442 проверки: классификатор, политики, аудит, инъекции,
#    ПДн, корпоративная политика, syslog, дифф и логика правки выделения)
./releng/test.sh

# 3. Установка (от root: миграция со старого плагина, dropins, регистрация)
sudo ./releng/install.sh

# 4. Удаление (от root)
sudo ./releng/uninstall.sh
```

CI (GitHub Actions) прогоняет сборку и тесты на матрице DBeaver CE
26.1.5/26.2.2 при каждом push/PR.

## Состав репозитория

```
bundles/com.aisql.dbeaver.core/   OSGi-бандл: классификатор, политики, аудит,
                                      AI-функции (тулбокс db)
bundles/com.aisql.dbeaver.ui/     OSGi-бандл: команды, страница настроек,
                                      вставка промптов, правка выделения ИИ,
                                      иконки
tests/src/                            офлайн-тесты (plain Java, без JUnit)
releng/build.sh                       сборка: build/ и dist/dropins/plugins/
releng/test.sh                        сборка + запуск тестов
releng/install.sh                     установка в системный DBeaver (root)
releng/uninstall.sh                   удаление из системного DBeaver (root)
releng/make-icons.py                  генерация иконок (воспроизводимо)
releng/verify-audit.py                проверка целостности журнала аудита
docs/                                 документация (см. docs/README.md)
```

## Совместимость

Плагин собирается против jar-ов **установленного** DBeaver (все плагины
в classpath), каталог установки — `/usr/share/dbeaver-ce` (переопределяется
`DBEAVER_HOME`). Проверено на DBeaver CE **26.1.5** и **26.2.2**;
используются только стабильные API (единственный зависимый от версии вызов
заменён на `UIUtils.asyncExec`). Более ранние версии не заявлены.
